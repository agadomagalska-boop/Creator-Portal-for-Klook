# Klook Kreator Portal

A cleaner, Klook-branded portal prototype for Klook Kreators (creators), built to replace the current affiliate dashboard.

## What Kreators can do

- **Join and sign up** through a simple step-by-step flow
- **Home**: earnings, level progress, videos posted this month, top performing video, and a "Needs your attention" list
- **Create ("What to post")**: content pillars, "always say" list, campaign briefs, Free tickets · Kreator Picks (1 free ticket for 1 video), and Klook Trips
- **Pick a destination** with country and city dropdowns or an interactive map, and see only what fits
- **Share**: top activities to promote with commission %, 3 talking points, what to include and avoid, plus tracked links and QR codes
- **Earnings**: overview, performance, levels, payouts, and usage rights (extra payout of $100–$500)
- **Chat** directly with the Kreator Manager, with topics
- **Flat-fee campaigns** with approval, and a draft pre-flight checklist

## Klook team view

Switch to "Klook team" in the profile menu to review applications, answer chats, approve drafts and post new opportunities.

## Notes

- This is a prototype. Earnings, performance and commission rates are **sample data**.
- Everything is in one file: `index.html`. No install or build step.
- Data is stored in the browser only.

## Run it

Open `index.html` in a browser, or use the GitHub Pages link.
